# Vorlage

Einzeiler, der sagt was das Artefakt ist und für wen.

## Spiel

- **Titel:** Name des Spiels — oder `allgemein`, wenn es um kein bestimmtes geht
- **Art:** Brettspiel / Kartenspiel / Würfelspiel / Rollenspiel / Sammelspiel
- **Spieler:** 2–4
- **Dauer:** ca. 60 Min

## Was das Artefakt tut

Zwei, drei Sätze. Wozu ist es da, was macht man damit, was ist der Nutzen am
Spieltisch.

## Woher

- **Chat:** Link oder Datum des Claude-Chats, aus dem es stammt
- **Stand:** JJJJ-MM-TT

## Offen

- Was noch fehlt oder unsicher ist
